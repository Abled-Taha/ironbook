# Security

This directory describes how Iron Book protects credentials, tokens, and user
data.

For reporting a vulnerability, see the [Security Policy](https://github.com/ironbook-labs/ironbook/blob/main/SECURITY.md)
(private disclosure only — never open a public issue for a vulnerability).

| Document | Contents |
| -------- | -------- |
| [Authentication](https://github.com/ironbook-labs/ironbook/blob/main/docs/security/authentication.md) | Password hashing, sessions, revocation |
| [Authorization](https://github.com/ironbook-labs/ironbook/blob/main/docs/security/authorization.md) | Service-layer access checks |
| [API tokens](https://github.com/ironbook-labs/ironbook/blob/main/docs/security/api_tokens.md) | Per-client tokens for privileged operations |
| [Secret management](https://github.com/ironbook-labs/ironbook/blob/main/docs/security/secrets_management.md) | Environment variables, `.env` handling |
| [Threat model](https://github.com/ironbook-labs/ironbook/blob/main/docs/security/threat_model.md) | Threats, mitigations, out-of-scope assumptions |
| [Audit logging](https://github.com/ironbook-labs/ironbook/blob/main/docs/security/audit_logging.md) | Security-relevant log events |
| [Security practices](https://github.com/ironbook-labs/ironbook/blob/main/docs/security/security_practices.md) | Disclosure, versions, dependencies, defense in depth |
