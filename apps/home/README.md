# Iron Book Project Website

The public project website for Iron Book, built with Next.js.

## Layout

- `src/` — site source
- `public/` — static assets
- `Dockerfile` — container image for the site
- `next.config.ts` / `package.json` — Next.js configuration and dependencies (pnpm)

## Development

Complete the root setup first (`scripts/ironbook.sh setup`).
Run `dev` and `test` tasks from the repository root, e.g. `mise run //apps/home/dev`.
